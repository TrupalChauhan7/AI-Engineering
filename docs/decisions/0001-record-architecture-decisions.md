# ADR 0001 — Record architecture decisions

**Status:** accepted

**Context:** The mark scheme rewards critical analysis. Writing down *why* we
made each choice (model, metric, threshold) makes that analysis easy and
defensible in the viva.

**Decision:** Keep short decision records here. One file per real decision, e.g.
"0002-why-llm-judge-over-rouge.md".

**Consequences:** A2/A3 report writing becomes mostly assembly of these notes.
