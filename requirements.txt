# =============================================================================
#  Speech-to-Clinical-Note — Python dependencies

#  This file lists the PYTHON libraries only. It does NOT install the three
#  other things the project needs, because they are not Python packages:
#
#     1. ffmpeg           (lets Whisper read audio)
#     2. Ollama + models  (medgemma:4b, llama3.1:8b, atla/selene-mini)
#     3. Node.js 20+      (only for the demo's web front-end)
#
#  The easy path installs ALL of the above for you:
#     Windows  ->  double-click  SETUP_WINDOWS.bat
#     Mac      ->  double-click  setup_mac.command
#  See README.md ("Quick start") for the one-double-click setup.
#
#  To install just these Python libraries by hand:
#     python -m venv .venv                 # make an isolated environment
#     source .venv/bin/activate            # (Windows: .venv\Scripts\activate)
#     pip install -r requirements.txt
#     pip install -e .                     # makes `import s2n` work everywhere
#
#  Version floors (>=) are set to the minimum known-good release so a fresh
#  install on a clean machine behaves the same as ours. Tested on Python 3.10–3.13.
# =============================================================================
